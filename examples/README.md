# Examples

Sample configuration and sanitised sample inputs/outputs for each skill.

| Path | What it is |
|---|---|
| [`qa-testing.config.yaml`](qa-testing.config.yaml) | A complete sample configuration with every option |
| `<skill-name>/` | Sample inputs and outputs for a skill — contributions welcome |

Sample reports from real runs are the most useful contribution right now. Run a skill against a
public demo app (see [Testing your skill](../CONTRIBUTING.md#testing-your-skill-before-you-open-a-pr)),
remove anything sensitive, and add the output under `examples/<skill-name>/`.
